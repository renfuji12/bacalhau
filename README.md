## 🌟 Overview
Bacalhau is a modern IPTV player equipped with GPU-accelerated HLS transcoding. It supports M3U playlists, Xtream Codes API, and EPG guides, making it a versatile tool for your streaming needs. Whether you're using NVIDIA NVENC for hardware encoding or the built-in capabilities of AMD, Intel, or Apple, bacalhau has you covered. Enjoy seamless playback and server-side playlist storage that maintains your preferences across devices.
